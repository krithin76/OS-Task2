Working Principle

1. Monitor: Encapsulates shared data and procedures so only one process executes monitor code at a time.

2. startRead(): A reader waits on canRead if a writer is active or waiting.

3. endRead(): The last reader signals canWrite when a writer is waiting.

4. startWrite(): A writer waits on canWrite until all readers and writers leave the database.

5. endWrite(): The writer signals another waiting writer first, or signals readers if no writer is waiting.
